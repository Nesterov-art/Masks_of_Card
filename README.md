# Masks of Card — Processing & Masking Financial Data

Python-сервис для обработки, фильтрации и маскирования чувствительных финансовых данных (номеров банковских карт, счетов и транзакций). Поддерживает импорт данных из форматов JSON, CSV и XLSX.

## 🚀 Функциональность

- **Маскирование данных (Data Anonymization):** Автоматическое скрытие номеров карт и счетов в соответствии со стандартами безопасности.
- **Мультиформатный импорт:** Обработка выписок по операциям из файлов `.json`, `.csv` и `.xlsx`.
- **Фильтрация и сортировка:** Сортировка транзакций по дате и статусу выполнения (APPROVED, CANCELED и др.).
- **Покрытие тестами:** Полное модульное тестирование бизнес-логики с использованием `pytest`.

## 🛠 Технологический стек

- **Язык:** Python 3.10+
- **Обработка данных:** `pandas` / `openpyxl` (для XLSX), `csv`, `json`
- **Тестирование:** `pytest`, `pytest-cov`
- **Инструменты:** Git, PyCharm / VS Code
